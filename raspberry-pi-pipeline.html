CSU DOMINGUEZ HILLS / RESEARCH PROJECT

Raspberry Pi Cluster
SSH Pipeline

An automated research system that collects, analyzes, and stores data from electrochemical double-layer capacitor (EDLC) tests. Eight paired Arduino and Raspberry Pi stations work together with an Ubuntu Linux server to run measurements and keep the results in one place.

Arduinos collect electrical measurements, while Python software on the Raspberry Pis processes the data and creates graphs. SSH lets the server remotely start software on the stations. NFS shared folders collect the results on the server, and Rclone synchronizes the data and graphs with cloud storage.

How the pipeline works

From capacitor measurements to shared research data.

  1. 01

    Collect measurements

    Arduinos record analog electrical measurements during timed charge and discharge cycles. Internal pull-up resistance measurements help support the capacitance calculations.

  2. 02

    Analyze with Python

    Each Raspberry Pi station uses Python automation to collect and process capacitance data, generate statistics, and plot capacitance against time with exponential and power fits.

  3. 03

    Gather results on the server

    The stations connect through an Ethernet local network. NFS shared folders bring text files and graphs to the Ubuntu server, while SSH provides remote control of the client software.

  4. 04

    Synchronize cloud storage

    Rclone synchronizes server folders with cloud storage. Scheduled systemd services run the uploads at intervals, completing the automated collection-to-storage pipeline.
