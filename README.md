# Daniel Amaya Gamero — Portfolio

A responsive portfolio built with plain HTML, CSS, and JavaScript.

## View locally

Extract the files together and open `index.html` in a modern browser. No build step or package installation is required.

## Pages

- `index.html`: About Me, Papers, Projects, and Contact.
- `medical-record-organizer.html`: project description, app workflow, and desktop wireframes.
- `raspberry-pi-pipeline.html`: research pipeline description and poster.
- `arduino-python-analytics.html`: Python code explanation, source code, and voltage graph.

## Edit the site

Edit the HTML pages for text and links. Shared styles are in `styles.css`; project-specific styles use separate CSS files. Keep the `assets/` directory beside the pages.

Images open in a full-size viewer. The contact link opens a vCard on mobile devices and copies the phone number on desktop browsers with clipboard access.

## Hosting

Upload these files to any static website host. `index.html` is the entry page. This package contains website source and assets, without hosting credentials or provider configuration.
