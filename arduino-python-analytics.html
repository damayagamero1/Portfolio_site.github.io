Analytics Graphing App

A Python script that turns recorded battery voltage measurements into a graph and an Excel workbook. It reads a text file, calculates average voltage for each group of 1,000 measurements, and shows how much the readings vary with standard deviation error bars.

The supplied example analyzes a copper–brass battery test. Pandas handles the data, and Matplotlib displays the graph. This script works with measurements already saved in a file.

What the code does

Read the measurements, summarize them, visualize their variation, and export the data.

  1. 01

    Read the test file

    The script loads a text file with two columns: time in milliseconds and voltage in volts. Spaces or tabs separate the values. It also creates a time-in-seconds column by dividing the original time by 1,000.

  2. 02

    Group 1,000 readings

    Rows are grouped by their position: the first 1,000 rows form one group, the next 1,000 form another. Each group produces a mean time, mean voltage, and sample standard deviation of voltage. The final group can contain fewer than 1,000 readings.

  3. 03

    Plot the averages

    Blue dots show mean voltage at each group's mean time in milliseconds. Red error bars extend one standard deviation above and below each average, showing the spread of readings within the group. The points are not connected by lines.

  4. 04

    Export to Excel

    The workbook keeps every original measurement, with time in milliseconds, time in seconds, and voltage, on a sheet named “Voltage Data.” The grouped summary is used for the graph and is not written to the workbook.

Reading the results

Groups contain 1,000 measurements, rather than fixed 1,000-millisecond intervals. The graph uses averaged time in milliseconds; the seconds column is included in the export. The error bars describe variation within each group, not a confidence interval. In a typical desktop run, closing the graph window lets the script continue to the Excel export.

The Python code

The complete script, including graph labels and the Excel export.

import pandas as pd
import matplotlib.pyplot as plt

input_file = "CopperBrassBattery_Test_09-23-2026-10-25-00.txt"
output_file = "CopperBrassBattery_Test_09-23-2026-10-25-00.xlsx"

# Read the two columns separated by tabs or spaces
data = pd.read_csv(
    input_file,
    sep=r"\s+",
    names=["Time (ms)", "Voltage (V)"],
    engine="python"
)

# Convert milliseconds into seconds
data["Time (seconds)"] = data["Time (ms)"] / 1000
group = data.index // 1000

summary = data.groupby(group).agg(
    average_time=("Time (ms)", "mean"),
    average_voltage=("Voltage (V)", "mean"),
    voltage_std=("Voltage (V)", "std")
)

plt.errorbar(
    summary["average_time"],
    summary["average_voltage"],
    yerr=summary["voltage_std"],
    fmt="o",           # Scatter points without connecting lines
    markersize=5,
    capsize=4,         # Horizontal caps on error bars
    color="blue",
    ecolor="red",      # Error-bar color
    elinewidth=1,
    label="Average voltage ± standard deviation"
)

plt.xlabel("Time (ms)")
plt.ylabel("Average Voltage (V)")
plt.title("Average Voltage Every 1000 Measurements")
plt.grid(alpha=0.3)
plt.legend()
plt.show()
# Put the columns in a convenient order
data = data[["Time (ms)", "Time (seconds)", "Voltage (V)"]]

# Save as an Excel workbook
data.to_excel(output_file, index=False, sheet_name="Voltage Data")

print(f"Excel file created: {output_file}")
